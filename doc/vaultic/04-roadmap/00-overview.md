# Roadmap Overview

[← Back to index](../README.md)

This is the tactical execution plan that implements the strategy in
[Vision, Scope, and Non-Negotiable Guarantees](../01-strategy/01-vision-and-principles.md)
and the design in [Architecture](../02-architecture/00-overview.md). Phases are grouped
into five milestones; each links to full goals, implementation steps, tests, and
exit criteria for its phases.

## Phase groups

| Phases | Milestone | Status |
|---|---|---|
| 0–4 | [Foundation: native build, protocol, engine abstraction, schema, legacy import](01-foundation-phases-0-4.md) | see phase detail |
| 5–8 | [Core operations: crawl reconciliation, dual-write/export, CLI, prune/GC](02-core-operations-phases-5-8.md) | see phase detail |
| 9–12 | [Pack lifecycle: tier model, history rollups, introspection, backend placement](03-pack-lifecycle-phases-9-12.md) | see phase detail |
| 13–15 | [Path history and placement scheduling](04-path-and-placement-phases-13-15.md) | see phase detail |
| 16–19 | [Analytics, compliance, and scale-out](05-analytics-compliance-scale-phases-16-19.md) | see phase detail |
